"inverse hypervisor." A normal hypervisor splits one machine into many VMs. This fuses many machines into one logical computer that runs functions. No k8s, no containers, no microVMs just blocks of metal that execute content-addressed code, and a language that handles the hard parts (distributed eval + hashing) so the user just plugs in more hardware.
